# **Fashion House Idea 👗**

**Fashion House Idea** is a responsive women's fashion website developed using **HTML, CSS, Bootstrap, and JavaScript**. The project showcases a modern online fashion store where users can browse fashion products by category and view stylish collections in an attractive interface.

## **🚀 Features**

- Responsive design for desktop and mobile devices
- Category-based product filtering
- Attractive fashion product gallery
- Modern user interface using Bootstrap
- Easy navigation between sections
- Product cards with images and details
- Clean and organized website layout

## **🛠️ Technologies Used**

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Git & GitHub
